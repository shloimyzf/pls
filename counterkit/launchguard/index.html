That one block means: no login needed to dump every user record, rewrite any price, promote any account to admin, or delete everything — with a single API call from a browser console. "Test mode" rules expire after 30 days; teams routinely re-open them to keep building and forget. Launch day is not when you want to find out.

Locking this down properly is not a one-line change. Owners, roles, field allowlists, server-only status changes, size caps, App Check, backups, claim management — each archetype fails differently. LaunchGuard is that work, done once, written to be adapted in an afternoon.
